# مسار — منصة لجنة إدارة المشاريع

المنتج الأساسي الآن موقع Next.js ذاتي الاستضافة في `web/`، مع PostgreSQL
للحسابات والمشاريع والخطط والمقترحات والمراجعات وسجل البريد. ملفات Apps Script
الأصلية محفوظة كمرجع واختبارات توافق.

## تشغيل الموقع

```bash
npm install
cp web/.env.example web/.env.local
npm run build
npm start
```

لا يوجد محرك نموذج متصل. المراجعة يدوية، والمعيار السادس يبقى معطلاً حتى
تعتمد اللجنة الأرقام المركزية. إرسال النتيجة يبقى مقفلاً إن لم تُضبط إعدادات SMTP.

## ملفات Apps Script المرجعية

| الملف | وش فيه |
|---|---|
| `00-الخطة-الكاملة.md` | الوضع الحالي، المراحل الثلاث، ما انحسم، الترتيب |
| `01-قرارات-مطلوبة-منك.md` | القرارات اللي توقف الشغل. اقرأه ثاني شي |
| `phase-1-intake/` | جاهز للتركيب اليوم |
| `phase-2-review/` | تنفيذ المرحلة ٢ كاملاً: التواريخ، البربوزل، تقييم الروبريك، مراجعة القائد والإرسال |

## الترتيب

1. ركّب `phase-1-intake` وجرّبه على ٣ مشاريع سابقة تعرف حجمها
2. أصلح الوثائق الأربع (القسم ٤ في ملف القرارات)
3. عبّئ الإعدادات والمعايرة الناقصة الموضحة في `phase-2-review/SETUP.md`
4. ركّب ملفات `phase-2-review/` في مشروع Apps Script واتبع دليل الإعداد

الخطوة ١ و٢ ما تنتظران شي.

## ملفات المرجع

ملفات الروبريك والأرقام والموجز الداخلي موجودة في جذر المجلد. ورقة الأرقام
ما زالت تحتاج تعبئة القيم الفعلية قبل الاعتماد التشغيلي الكامل.
