# المرحلة ٢أ — فحوصات الخط الزمني

تشتغل على خطة المشروع قبل ما يُرفع أي بربوزل. أغلبها فحوصات آلية بحتة، ما تحتاج مودل.

---

## المعالم الإلزامية

الفريق يعبّي تاريخاً لكل معلم ينطبق على مشروعه.

| المعلم | صغير | متوسط | كبير | تقني |
|---|:---:|:---:|:---:|:---:|
| إقرار الفكرة | ✓ | ✓ | ✓ | ✓ |
| إغلاق الرعاية (آخر موعد لتأكيد راعٍ) | — | ✓ | ✓ | — |
| تسليم التصاميم النهائية | — | ✓ | ✓ | — |
| فتح التسجيل | ✓ | ✓ | ✓ | — |
| إغلاق التسجيل | ✓ | ✓ | ✓ | — |
| إعلان المقبولين | — | ✓* | ✓* | — |
| بداية الحدث | ✓ | ✓ | ✓ | — |
| نهاية الحدث | ✓ | ✓ | ✓ | — |
| تسليم التقرير الختامي | ✓ | ✓ | ✓ | ✓ |

\* للهاكاثونات والمعسكرات فقط، اللي فيها قبول انتقائي.

---

## الفحوصات

### T1 — التسلسل ⛔
كل تاريخ لاحق أكبر من سابقه بالترتيب أعلاه. أي انعكاس يرجّع الخطة فوراً.

### T2 — الاكتمال ⛔
كل معلم إلزامي لحجم المشروع فيه تاريخ. الفراغ يرجّع الخطة.

### T3 — المسافات الدنيا ⛔
مقارنة بالعتبات المستخرجة من بربوزل فنتك. عبّها في `CONFIG.MIN_GAPS`:

| المسافة | الحد الأدنى |
|---|---|
| فتح التسجيل ← بداية الحدث | `___` أسبوع |
| إغلاق التسجيل ← إعلان المقبولين | `___` يوم |
| إعلان المقبولين ← بداية الحدث | `___` يوم |
| إغلاق الرعاية ← تسليم التصاميم | `___` يوم |
| تسليم التصاميم ← فتح التسجيل | `___` يوم |
| نهاية الحدث ← التقرير الختامي | `___` يوم |

> **مصدر الأرقام:** بربوزل فنتك، وهو الوحيد اللي أخذ **قوي** في معيار الخط الزمني بالروبريك. قوام أخذ **مقبول** فقط فلا يُستخدم مرجعاً هنا.

### T4 — تعارض التقويم ⚠️
تنبيه غير حاجب إذا وقع الحدث أو فترة التسجيل داخل:

- فترة الاختبارات النهائية أو النصفية
- رمضان
- إجازة عيد الفطر أو الأضحى
- الإجازة الصيفية
- أسبوع فيه مشروع نادٍ آخر معتمد (يحتاج جدول المشاريع المعتمدة)

التقويم الجامعي يُعبّأ مرة كل سنة في `CONFIG.ACADEMIC_CALENDAR`.

### T5 — هامش الخطأ ⚠️
تنبيه إذا كان بين آخر مهمة تحضيرية وبداية الحدث أقل من `___` أيام. وثائق النادي تطلب هامش خطأ صراحة، وأغلب الخطط تسلّمه صفراً.

### T6 — اتساق هجري/ميلادي ⛔
لو الخطة فيها التاريخين، لازم يتطابقان. هذا نفس البند في المعيار الثامن بالروبريك، ويُفحص هنا مبكراً بدل ما ينتظر مرحلة البربوزل.

---

## المخرج

| النتيجة | الشرط | الإجراء |
|---|---|---|
| **معتمد** | ما فيه ⛔ ولا ⚠️ | يُفتح رفع البربوزل للفريق |
| **معتمد بتنبيهات** | ما فيه ⛔، وفيه ⚠️ | يُفتح الرفع، والتنبيهات ترافق البربوزل لقائد اللجنة |
| **إعادة تقديم** | فيه ⛔ واحد أو أكثر | الرفع مقفل، وترجع للفريق قائمة الأخطاء |

الرد للفريق يذكر المعلم والتاريخ المدخل والقاعدة اللي انكسرت والحد الأدنى المطلوب. ما يعطيهم تواريخ بديلة، لأن اختيار التاريخ قرارهم مو قرار النظام.

---

## ما لا تفحصه هذه المرحلة

جودة المحتوى، الأهداف، الباقات، الهوية، الأرقام السابقة. كلها في الروبريك بالمرحلة ٢ب. هذه المرحلة تواريخ فقط.
